# 에이전트 공통 핸드오프

이 문서는 Codex와 Claude가 함께 읽는 추적 가능한 작업 기록이다. 도구별 지침은 각각 `AGENTS.md`와 `CLAUDE.md`에 두고, 현재 상태와 두 도구가 함께 알아야 할 결정은 여기에 한 번만 기록한다.

## 운영 규칙

- 작업을 시작할 때 이 문서와 현재 Git 상태를 먼저 확인한다.
- 작업을 마칠 때 다음 세션에 필요한 현재 상태, 검증 결과, 남은 일을 갱신한다.
- `.memory/MEMORY.md`는 선택적인 로컬 상세 기록이다. 파일이 없어도 작업은 계속한다.
- `.codex/config.toml` 같은 개인 도구 설정은 사용자가 요청하지 않는 한 공유 커밋에 포함하지 않는다.
- 여러 에이전트가 같은 워킹트리를 쓸 수 있으므로 다른 에이전트의 변경과 프로세스를 건드리지 않는다.
- 패키징, 릴리스, 배포는 사용자가 명시적으로 요청했을 때만 작업 범위에 포함한다.
