# 인라인 음성·영상

결과 파일은 프로젝트·출력 폴더에 저장한다. Claude Code와 Codex는 `mediaopen --block FILE`의 반환 블록을 답변에 그대로 넣고 블록 밖에 파일 링크를 남긴다. 공유폴더 목록·의무 복사는 사용하지 않는다. 본문 카드를 누르면 앱 미리보기에서 재생하며, 결과를 출력한 것만으로 소리·별도 창·외부 앱을 열지 않는다.

## 표시와 재생

표식은 fenced text 안의 `[[km:<16자리 소문자 hex>:00/12]]`다. 음성은 4행, 영상은 12행을 쓴다. 각 행은 같은 ID·전체 행 수와 순차 행 번호를 가진다. 이미지 `[[ki:…]]`와 독립이다. PC는 화면에 남은 행 번호로 스크롤 클리핑을 복원하며 다른 문장에 포함된 표식은 치환하지 않는다. 폰 대화는 완전한 fenced 블록만 카드로 바꾼다.

카드는 파일명·길이·영상 썸네일을 표시한다. 재생은 명시적 클릭 뒤 시작한다. PC는 AVFoundation의 음성 시계와 영상 프레임을 사용하고 wgpu 텍스처를 갱신한다. macOS가 지원하는 코덱만 재생할 수 있다. 비 macOS PC의 플레이어는 지원하지 않는다는 오류를 반환한다. iOS는 네이티브 미디어 재생을 사용한다.

재생·정지, 탐색, 음소거, 종료는 미리보기 안에서 처리한다. PC Space는 재생·정지, 좌우는 5초 이동, Esc는 닫기다. 미리보기의 키·IME·클릭을 뒤 터미널에 보내지 않는다. 드래그가 4px를 넘으면 기존 텍스트 선택으로 돌려준다. 창이 초점을 잃으면 멈추고, 닫기·방 전환·별도 터미널 창 제거는 디코더를 해제하고 다운로드를 취소한다. 배경에서 받기가 끝났다고 재생을 시작하지 않는다.

## 등록과 원격 읽기

`kasa_socket::inline_media`가 파일을 스트리밍 복사·해시 계산한 뒤 기기 전용 캐시에 등록한다. 등록 중 파일이 바뀌면 실패한다. 원본을 옮기거나 지워도 등록된 내용은 남는다. 기본 경로는 설정 폴더의 `inline-media`, 격리 실행은 `KASATERM_INLINE_MEDIA_DIR`를 사용한다. 이 저장소는 공유폴더 화면이나 동기화 대상 목록이 아니다.

원본 파일은 SHA-256 내용 주소, 카드는 이름·종류·길이·포스터 등을 포함한 메타데이터 주소를 가진다. **카드 ID는 파일 SHA-256의 접두사가 아니다.** 등록은 로컬 CLI만 수행한다. HTTP는 경로 대신 이미 등록된 ID만 받으며 일반 원격 인증과 소유자 권한을 요구한다. 게스트는 읽을 수 없다.

| 요청 | 반환 |
|---|---|
| `GET /term/inline-media?id=ID` | 버전·ID·종류·이름·MIME·크기·파일 SHA-256·길이·해상도·포스터 유무 |
| `GET /term/inline-media/poster?id=ID` | 제한된 PNG 썸네일 |
| `GET /term/inline-media/file?id=ID&offset=N&len=N` | 원본 파일 조각 |

파일 상한은 1GiB, 서버 조각 상한은 8MiB, 클라이언트 요청은 4MiB다. 포스터는 12MiB·긴 변 1600px 이하다. 잘못된 ID·범위는 400, 없거나 변형된 등록물은 404로 처리한다. 응답에 기기 내부 경로를 넣지 않는다.

미러·폰은 대화의 원본 기기에 메타데이터를 요청한다. 큰 파일은 카드 클릭 뒤 조각으로 받아 파일에 기록하고 크기·전체 SHA-256을 검증한 뒤 재생한다. 전체 파일을 메모리에 적재하지 않는다. 취소·무결성 실패의 임시 파일은 버린다. 폰은 연결 실패 뒤 남은 조각의 해시를 다시 계산해 이어 받을 수 있고, 이미 확인한 카드·파일은 원본이 꺼져도 캐시에서 재생한다. 기존 일반 파일 링크의 32MiB 한도와 별개이며, HTTP Range 스트리밍을 제공하는 API는 아니다.

## 검증

`docs/verify-app.md`의 격리 앱 환경에 미디어 캐시 경로도 따로 지정한다. 무음 오디오·색이 바뀌는 짧은 영상·회전 영상으로 카드, 재생 진행, 일시정지, 탐색, 종료, 방향을 검사한다. 원격은 서로 다른 캐시의 앱 두 개를 연결해 원본 파일 수신을 확인한다. 32MiB를 넘는 파일, 파일 해시 불일치, 연결 끊김, 취소와 재시도, 게스트·무인증 거절을 포함한다. 사용자 세션이나 운영 앱을 재시작하지 않는다.
