## v0.2.1 — 공증된 판, 폰과 여러 기기를 한 손에

`v0.2.0` 이후 852 커밋(새 기능 339 · 수정 374).

### 처음으로 공증된 mac 판

- mac dmg 를 Developer ID 로 서명하고 애플 공증을 받는다. 처음 열 때 「우클릭 → 열기」가 필요 없다.
- 계정 메뉴 바닥의 **판 번호 줄**을 누르면 그 기기의 업데이터(Sparkle·WinSparkle)로 새 판을 받는다.
- 여러 기기에 한 판을 차례로 올리는 기기 업데이트 창구가 들어갔다(기본 꺼짐) — 공식 릴리스만 받아 해시·서명·팀·공증을
  확인하고, 바쁜 학생이 없을 때 갈아 끼우며, 새 판이 뜨지 않으면 되돌린다.

### 폰

- **카사모바일 작업판** — 학생마다 현재 작업·변경·다음 일·막힘·검증을 한 줄로, 누르면 정리 시트. 승인이 필요한 일이 먼저 온다.
- **폰 허브** — 기계별 방 목록을 접고 펴고, 지도 덱을 넘겨 본다.
- 학생 화면이 두 얼굴을 가진다 — 터미널 격자와 대화 말풍선. 친 글자가 곧바로 입력상자에 붙는 「바로 치기」, 지난 줄로 바로
  올라가는 딥링크, 격자의 주소를 눌러 열기·복사.

### 여러 기기

- 사이드바 미니맵에서 기기 사이로 칸을 끌어 놓으면 그 기기로 이사한다. 다른 기기 칸도 본기기처럼 우클릭·닫기·쪼개기·탭이 된다.
- 셸에서 `to <기계>` 하나로 기계를 오간다(`to` 는 목록, `to ..` 는 돌아오기).
- 기계끼리 클립보드를 나누고, 폰과 「최근 복사」를 나눈다 — 비밀값은 가린다.
- 거울 보기 창이 원본 방의 쪼갠 방향·새 pane·탭을 그대로 따라간다.

### 펫

- 데스크톱 펫이 묻지 않아도 먼저 말을 걸고, 일을 받아 학생에게 넘긴다.

### 카사크롬

- MCP 를 거치지 않는 터미널 진입점 `kc`. 폰을 브라우저 기기로 쓰면 학생 도구가 보여 줄 페이지 링크를 돌려준다.

### 계정 · 설정 · 하단바

- 브라우저가 주운 로그인 코드를 앱이 직접 받는다. 한도 경고는 90% 에서 한 번씩, 연결된 기기는 같은 Claude 계정을 따라간다.
- 계정별 사용량 그래프. 하단바의 원격 칩을 「모바일」 하나로 모았다(QR 로 앱 열기·설치·웹 보기).
- 판 번호를 누르면 「새 판」 팝오버 — 굽기 · 다른 기계로 보내기 · 기계 설정.

### 문서

- 볼트 시작 화면과 문서 목록, 블록 삽입 메뉴·행 이동, 문서 사이 연결 그래프.

### 협업

- 통합 보드와 안전한 메시지 전달 — 기계가 달라도 이름 하나로 보내고, 영수증으로 전달을 확인한다.
- 보드 첫 탭 「작업현황」은 사람용, 「관측」은 에이전트용으로 갈랐다.

### 그 밖

- 라이트 모드 — 켤 때마다 새 셸, 세션 저장·복원 없이 가볍게.
- 스크롤 띠의 「맨 아래로」, 이 창만 본화면 렌더러로 보는 `claude classic`, codex 프롬프트 앵커.
- pane 안 탭도 저장·복원한다.
