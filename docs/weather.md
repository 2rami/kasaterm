# 날씨 — 리퀴드 비 설정 모델

카사텀 창·카드·단추에 비를 내린다. 필터가 아니라 **요소마다** 반응한다 — 창마다 제 유리, 단추마다 제 물방울.
시제품: `KASA-share/2026-09-29-리퀴드-비-시제품/`(폰·데스크톱 1·2차), 가지 `draft/liquid-rain-desktop`·`draft/liquid-rain-mobile`.

## 설정 (전부 사용자가 고른다)

| 항목 | 값 | 기본 |
|---|---|---|
| 날씨 | 켬 / 끔 | 끔 |
| 비 양 | 없음 · 이슬비 · 비 · 폭우 | 이슬비 |
| 바람 | 방향 −1~1 · 세기 0~1 | 0 · 0 |
| 어디에 | 전체 창 · 초점 창만 · 초점 아닌 창만 · 고른 창만 · 창 밖 배경만 | **초점 창만**(2026-09-29 선생님 선택) |
| 효과 | 빗줄기 · 창 물방울 · 김서림 · 파문 · 단추 물방울 — 하나씩 켜고 끔 | 전부 켬 |
| 닦기 | 입력하면 · 초점 오면 · 안 닦음 | 입력하면 |
| 다시 젖는 시간 | 30초 ~ 10분 | 3분 |
| 학생 상태 날씨 | 끔 / 켬 — 켜면 상태마다 비 양(하는 중 · 내 차례 · 쉬는 중) | 끔 |
| 창별 덮어쓰기 | 창 우클릭 「이 창 날씨」: 설정 따름 · 맑음 · 비 양 고정 | 설정 따름 |

- 「어디에」와 창별 덮어쓰기가 부딪히면 **창별이 이긴다**. 학생 상태 날씨는 비 양만 바꾸고 「어디에」는 그대로 따른다.
- 앱에 넣는다, 기본은 끔(2026-09-29 결정). 끈 사람은 셰이더 비용 0.
- 글 보호: 글자 위에서는 굴절을 상한까지만 건다(시제품 1차에서 글이 뭉개져 절반으로 낮춘 값이 기준). 초점 창의 입력줄은 어떤 설정이어도 물방울을 올리지 않는다.
- 접근성: OS 「동작 줄이기」면 움직임을 멈추고 맺힌 물방울만 남긴다. 「투명도 줄이기」면 날씨를 끈다. 사용자가 날씨 설정에서 「OS 설정 무시」를 켤 때만 예외.

## 데스크톱 구현 (`app/kasaterm/src/weather/`)

- `model.rs` 설정·판정(순수 함수), `sim.rs` 창별 물방울·와이퍼·고임·단추 물방울의 몸, `gpu.rs`+`shaders/` 패스.
- 앱 프레임을 표면에 그린 뒤 표면을 한 장 복사해 입력으로 쓰고 결과를 표면에 다시 쓴다(Metal 표면은 샘플링 불가).
  순서: 빗줄기(반해상도) → 프레임+빗줄기 → 판 파문 → 창 유리(물 지도·흐림·합성) → 단추 물방울.
- 창 상자·초점은 `render_frame_gpu` 의 창 상자, 입력줄은 초점 창의 `prompt_box`(없으면 커서 줄). 판은 사이드바·왼쪽 판·파일 열·오른쪽 열,
  줄은 머리줄·하단바. 단추 자리는 그 장에 `native_controls` 가 그린 조작 + 머리줄 토글·하단바 계정/판 번호 히트 사각형(한 장 늦게 반영).
- 비만 움직이는 장은 화면을 다시 짓지 않고 마지막 프레임 복사본 위에 날씨 패스만 다시 그린다(30fps 펌프). 캡처가 걸려 있으면 전체 장.
- 꺼져 있으면 GPU 자원·펌프·단추 수집이 없다. 설정 화면이 열려 있는 동안 창 자리는 마른다(글을 읽는 곳).
- 글 보호 값: 연속 굴절(판 파문·빗줄기 휨·고임·단추 고리) 상한 7 논리 px. 창 물방울 속의 뒤집힌 상은 물방울 안에서만 보인다.
- 창 우클릭은 사이드바 창 줄 우클릭 메뉴(날씨가 켜져 있을 때만 여섯 줄). 값은 session.json `pane_weather`(surface key → 값).
- 계정 동기화 키 `weather` 는 `OPT_IN_KEYS` — 관문을 다시 배포해야 기기 사이로 오간다(그 전엔 로컬 유지).

## 폰 (`mobile/lib/weather/`)

같은 모델이다. 「창」은 카드, 「초점」은 방금 만지거나 스크롤한 카드. 폰은 배터리를 고려해 기기별로 따로 고를 수 있다
(계정 동기화에서 「날씨는 기기마다」 선택).

- `model.dart` 설정·판정(데스크톱 `model.rs` 와 같은 JSON), `store.dart` 저장·계정 동기화(`/relay/account-sync` 에
  `x-kasa-sync-keys: weather`)·카드별 덮어쓰기·초점, `sim.dart` 카드 유리의 물, `card.dart` 카드, `scene.dart` 화면 층,
  `sheet.dart` 설정 「날씨」 시트·「이 카드 날씨」.
- 카드 = 허브 방 상자·작업 줄(`WeatherCard`). 화면 층(`WeatherScene`) = 나쵸 첫 화면(대화·작업)·허브·학생 대화 보기.
  설정·터미널·모달에는 두지 않는다(글을 읽는 곳, 대화 말풍선·모달은 design.md 예외 그대로).
- 단추 물방울은 A 판 단추를 바꾸지 않고 위에 얹는다. 화면 층이 300ms 마다 자기 아래를 훑어 테마 단추(Text·Outlined·
  Filled·Icon·FAB·칩·Cupertino)를 모으고, 한 줄에 12pt 안으로 붙은 것을 한 무리로 잇는다. 카드 안 단추는 그 카드의
  비 양, 밖은 바탕 비 양을 따라 비가 없으면 마른다. 뒤를 비추지 않는 막이라 단추 글은 굴절되지 않는다.
- 카드가 젖으면 카드 모습을 몇 초에 한 번 떠서(물방울 렌즈가 비출 상) 바탕을 깐다 — A 판 카드는 투명해서 그대로 뜨면
  방울이 검게 뜬다. 파문은 유리 표면의 빛 고리라 글을 밀지 않고, 물방울 속 뒤집힌 상은 방울 안에서만 보인다.
- 닦기 「입력하면」: 카드 빈 곳을 만지거나 그 카드에서 스크롤하면 손길 자리를 훔치고 손을 뗄 때 한 번 쓸어 닦는다.
  단추만 누르면 누른 자리만(단추에서 18pt 넘게 끌면 스크롤로 본다). 「초점 오면」: 다른 카드에서 넘어올 때 한 번.
- 입력칸(EditableText) 자리는 빗줄기를 비우고 단추 물방울을 올리지 않는다. 카드 안에는 입력칸을 두지 않는다.
- 접근성: 「동작 줄이기」 = `MediaQuery.disableAnimations`, 「투명도 줄이기」 = 앱 다리 `kasaterm/a11y`
  (`UIAccessibility.isReduceTransparencyEnabled`, 바뀌면 알림).
- 검증용 빌드 스위치 `KASA_WEATHER`(설정 JSON) — 켜면 그 값으로 뜨고 계정과 주고받지 않는다.

## 구현 원칙

- 창 사각형·초점·입력은 앱 상태에서 직접 읽는다(시제품의 캡처 템플릿 매칭은 쓰지 않는다).
- 비 양·효과를 전부 끄면 셰이더 패스를 건너뛴다 — 끈 사람은 비용 0.
- 설정은 계정 설정으로 기기끼리 동기화, 창별 덮어쓰기는 그 기기 세션에만 저장.
