# 날씨 — 리퀴드 비 설정 모델

카사텀 창·카드·단추에 비를 내린다. 필터가 아니라 **요소마다** 반응한다 — 창마다 제 유리, 단추마다 제 물방울.
시제품: `KASA-share/2026-09-29-리퀴드-비-시제품/`(폰·데스크톱 1·2차), 가지 `draft/liquid-rain-desktop`·`draft/liquid-rain-mobile`.

## 설정 (전부 사용자가 고른다)

| 항목 | 값 | 기본 |
|---|---|---|
| 날씨 | 켬 / 끔 | 끔 |
| 비 양 | 없음 · 이슬비 · 비 · 폭우 | 이슬비 |
| 바람 | 방향 −1~1 · 세기 0~1 | 0 · 0 |
| 어디에 | 전체 창 · 초점 창만 · 초점 아닌 창만 · 고른 창만 · 창 밖 배경만 | **초점 창만**(2026-09-29 선생님 선택) |
| 효과 | 빗줄기 · 창 물방울 · 김서림 · 파문 · 단추 물방울 — 하나씩 켜고 끔 | 전부 켬 |
| 닦기 | 입력하면 · 초점 오면 · 안 닦음 | 입력하면 |
| 다시 젖는 시간 | 30초 ~ 10분 | 3분 |
| 학생 상태 날씨 | 끔 / 켬 — 켜면 상태마다 비 양(하는 중 · 내 차례 · 쉬는 중) | 끔 |
| 창별 덮어쓰기 | 창 우클릭 「이 창 날씨」: 설정 따름 · 맑음 · 비 양 고정 | 설정 따름 |

- 「어디에」와 창별 덮어쓰기가 부딪히면 **창별이 이긴다**. 학생 상태 날씨는 비 양만 바꾸고 「어디에」는 그대로 따른다.
- 앱에 넣는다, 기본은 끔(2026-09-29 결정). 끈 사람은 셰이더 비용 0.
- 글 보호: 글자 위에서는 굴절을 상한까지만 건다(시제품 1차에서 글이 뭉개져 절반으로 낮춘 값이 기준). 초점 창의 입력줄은 어떤 설정이어도 물방울을 올리지 않는다.
- 접근성: OS 「동작 줄이기」면 움직임을 멈추고 맺힌 물방울만 남긴다. 「투명도 줄이기」면 날씨를 끈다. 사용자가 날씨 설정에서 「OS 설정 무시」를 켤 때만 예외.

## 폰

같은 모델이다. 「창」은 카드, 「초점」은 방금 만지거나 스크롤한 카드. 폰은 배터리를 고려해 기기별로 따로 고를 수 있다
(계정 동기화에서 「날씨는 기기마다」 선택).

## 구현 원칙

- 창 사각형·초점·입력은 앱 상태에서 직접 읽는다(시제품의 캡처 템플릿 매칭은 쓰지 않는다).
- 비 양·효과를 전부 끄면 셰이더 패스를 건너뛴다 — 끈 사람은 비용 0.
- 설정은 계정 설정으로 기기끼리 동기화, 창별 덮어쓰기는 그 기기 세션에만 저장.
