# 첫 설정과 설정 화면 개편

## 확정된 방향

- 기존 플랫·아웃라인 스타일과 활성 테마 토큰을 유지한다.
- 첫 설정은 핵심 선택만 빠르게 마치고 세부 항목은 펼쳐서 조정한다.
- 첫 설정에서 선택한 값은 일반 설정에서도 같은 이름과 선택지로 바꾼다.
- 실제 데스크톱 진입점인 네이티브 설정 방을 기준으로 구현한다.

## 공통 정보 구조

| 영역 | 첫 설정의 핵심 선택 | 펼치는 세부 항목 / 일반 설정 |
| --- | --- | --- |
| 캐릭터 | 캐릭터 테마 | 사용할 캐릭터, 개별 성격·그림·모델 |
| 모양 | 색상 테마, 둥글게·각지게·픽셀 | 강조색, UI 글꼴·배율, 대비 |
| 코딩 에이전트 | Claude Code·Codex 연결, 기본 에이전트, 권한 기본값 | 제공자별 모델·생각 깊이, 상태줄, 성격·협업 연결 |
| 터미널 | 기본 셸, 글꼴·크기 | 커서, 시작 위치, 스크롤 관련 설정 |

일반 설정의 보조 영역은 계정·연결 기기·앱 일반·앱 하단바·펫·피드백이다.
캐릭터 테마와 화면 색상 테마는 제목에서 구별한다. 앱 하단바와 에이전트 내부
상태줄도 독립된 항목으로 표시한다.

## 첫 설정

1. 캐릭터·모양·코딩 에이전트·터미널을 한 화면의 요약 행으로 보여 준다. 변경할 행만 펼친다.
2. 언제든 건너뛰거나 시작할 수 있고, 다른 영역을 펼쳐도 선택을 유지한다.
3. 세부 설정은 기본적으로 접는다. 로그인·오류·저장 결과는 접힌 영역 밖에서도 보인다.
4. 요약과 미리보기 아래에서 바로 시작한다. 별도 설명만 있는 완료 단계는 제거한다.
5. 기존 터미널 프로필 가져오기는 모양의 선택 가능한 경로이며 수동 설정을 가리지 않는다.

## 설정

- 첫 설정과 같은 영역 이름을 탐색 목록에 사용한다.
- 항목마다 설명·현재 값·조작을 한 행에 모으고, 관련 없는 고급 항목을 섞지 않는다.
- 외형은 변경 결과를 미리보기로 확인한다. 에이전트 상태줄은 정보 항목을 켜고 끈 결과를 보여 준다.
- 저장 실패를 표시하고 다시 시도할 수 있게 한다. 저장되지 않은 값을 저장 완료로 표시하지 않는다.
- 즉시 적용, 새 작업부터 적용, 재시작 필요를 실제 적용 범위에 맞게 표시한다.
- 계정 로그인·삭제와 일반 환경 설정의 조작을 구분한다.

## 구현 상태와 경계

- `native_onboarding.rs`는 네 단계 진행 대신 캐릭터·모양·코딩 에이전트·터미널의
  네 요약 행과 행 안의 펼침을 사용하는 단일 빠른 설정 화면이다. 터미널 글꼴과 가져오기는
  추가 펼침 안에 있으며, 시작·건너뛰기와 저장·재시작 안내는 고정 하단에 있다.
- `native_settings.rs`의 공통 설정 액션과 저장소를 공유한다. 활성 테마 토큰과 플랫·아웃라인
  행 구조를 유지하고, 데스크톱과 640×720 화면에서 스크롤 표시를 위한 여백을 둔다.
- `agent_preferences.rs`가 기본 에이전트, 제공자별 권한, 상태줄 표시를 저장한다.
  권한 선택은 실행 래퍼에 연결되어 있다. 값이 없는 기존 설치는 Codex의 제한 없는 실행과
  Claude의 기본 동작을 보존하고, 새 설치 초기화는 두 제공자 모두 `default`를 사용한다.
  잘못된 저장값은 `default`로 처리하고, 명시적인 CLI 권한 설정을 우선한다.
- 상태줄은 사용자 설정을 상속하는 상태와 앱에서 직접 조정하는 상태를 구별한다.
  직접 조정을 켠 뒤 모델·사용량·작업 경로를 선택하며, 끄면 기존 제공자 설정을 다시 따른다.
  Claude의 표시 항목을 숨겨도 협업 상태 보고는 유지한다.
- 웹 설정은 별도 구현이다. 이번 화면 검증 범위는 네이티브 첫 설정과 설정 방이다.

## 검증 결과

승인 방향: B안, 핵심 설정 요약과 필요한 항목 펼치기.
구현 완료: 빠른 설정 요약과 펼침, 공통 설정 연결, 에이전트 권한·상태줄 설정.

| 검증 항목 | 판정 | 근거 / 한계 |
| --- | --- | --- |
| 자동 검사 | PASS | `native_*` 67개, `agent_preferences` 5개, CLI 9개, Python 2개, Codex shim 불변식 1개 통과 |
| 열 가운데 정렬 회귀 검사 | PASS | 의도적으로 정렬을 깨뜨린 변형에서 실패함을 확인 |
| 격리 API와 저장 | PASS | 상태줄 직접 조정·개별 항목·권한·기본 에이전트·잘못된 입력·복원 검증, 저장값 유지 및 무관한 설정 구조 보존 확인 |
| 상태줄 상속과 직접 조정 | PASS | 상속 상태를 표시하는 전체 조정 스위치로 독립 검토 지적 해소 |
| 터미널 글꼴·스크롤 여백 | PASS | 글꼴 기본 접힘, 데스크톱·640×720 화면의 여백을 캡처로 확인 |
| 에이전트 안내와 상태 정리 | PASS | 네 개의 박스형 안내 제거, 불필요한 기본 에이전트 상태 제거 확인 |
| 고정 하단 피드백 | PASS (코드) | 스크롤 밖 표시 확인; 저장 실패 화면 캡처는 미실시 |
| 탐색 클릭 영역 | PASS (코드) | 본문 클리핑에서 고정 탐색 영역 분리 확인; 실제 클릭은 미실시 |
| 독립 검토 | PASS | 최초 주요 지적의 수정 결과 재검토 |
| 릴리스 빌드 | PASS | 서명된 `dist/kasaterm.app` 빌드 성공 |

전체 요약·모양·에이전트·터미널·좁은 화면을 캡처해 검수했다. 임시 시안·캡처·검증 로그는 작업 후 정리했다.
실제 제공자 세션, Windows 실기기, 저장 실패 UI는 실행 검증하지 않았다.
사용 중인 앱의 재시작도 수행하지 않았다. 따라서 빌드·격리 검증을 실사용 전 경로 검증으로 해석하지 않는다.

전용 디자인 검토자·에셋 제작자 역할을 사용할 수 없어 새 독립 일반 에이전트로 해당 검토를 수행했다.
새 프로덕션 비트맵은 필요하지 않았으며 기존 테마 이미지와 `SettingsMediaCache`를 사용한다.
