# Native collaboration board

Mode: Operate. 여러 기기에서 작업하는 사람이 모든 방의 요청·진행·완료 보고를 훑고, 확인이 필요한 창의 최근 근거를 펼친다.

Overview는 전체 기기를 기본으로 기기·방별 얇은 구분 행을 보여준다. 현재 터미널 팔레트, 시스템 글꼴과 기존 캐릭터 얼굴을 유지한다. 이름·상태·확인 시각 정렬은 사용자가 선택할 때 적용하며 갱신으로 기존 행 순서를 바꾸지 않는다.

방 필터는 기기와 방의 고정 식별값으로 유지하며 이름은 표시할 때만 쓴다. 방이 하나이거나 사라져도 필터를 해제할 수 있다. 최근 변경은 사건 당시의 방을 기준으로 표시하고 기기 전체의 연결 오류는 방 필터에서도 보여준다.

완료는 명시적 보고로만 표시한다. 대기, 확인 필요, 미확인, 오래된 정보, 연결 끊김을 구분한다. 수집 실패는 마지막 정보를 유지하며 최근 변경 기록을 이어받지 못하면 그 사실을 표시한다. 시간은 확인 시점 기준 상대 시간이다.

상세는 선택한 창의 제한된 최근 활동만 읽는다. 기기·고정 주소·세션·실행 신원과 선택 세대를 검사한다. 주소를 복사할 수 있으며 현재 로컬 창의 고정 주소가 일치할 때만 이동한다. 원격 미러를 새로 만들지 않는다.

보드의 저장은 비활성화한다. 기존 저장 경로는 나중에 창 번호만으로 키 입력을 보내므로 조회한 대화와 저장 순간의 대화가 같은지 보장하지 못한다. 저장은 해당 창에서 실행하도록 안내한다.

긴 한글과 URL은 실제 글자 폭으로 접고 클릭 영역도 클립 경계로 자른다. 데이터가 없거나 연결이 실패한 경우 그 상태와 다음 행동을 짧게 표시한다.

스케줄·소스 컨트롤·이사·백그라운드 에이전트 탭과 원래 작업 방으로 돌아가는 동작은 유지한다. Overview는 자체 보드 스냅샷과 변경 기록만 수집하며 다른 탭의 구형 수집기를 호출하지 않는다.

검증: 가상 기기·중복 창 번호·긴 문장·연결 오류·기록 유실·선택 전환 회귀를 포함한다. 실제 화면 검수와 통합 빌드는 통합 담당이 수행한다.

가상 보드 요청은 분리된 디버그 환경에서만 허용한다. 출시 빌드나 격리 설정 오류에서는 검증 오류를 표시하고 실제 운영 데이터로 넘어가지 않는다.
