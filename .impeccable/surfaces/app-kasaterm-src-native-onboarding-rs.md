# 빠른 설정과 설정 방

Mode: Operate. 첫 실행 사용자는 네 가지 핵심값을 확인하고 바로 시작한다.
기존 사용자는 같은 이름의 설정 영역에서 값을 다시 수정한다.

승인된 시안: `.impeccable/mocks/settings-onboarding-b.png`.
사용자 선택: 기존 플랫·아웃라인 스타일 유지, 핵심 요약 + 필요한 항목 펼침.
시안의 임의 콘텐츠와 카드 장식은 정본이 아니다. `docs/design.md`의 토큰과 행 구조를 유지한다.

첫 화면은 캐릭터·모양·코딩 에이전트·터미널의 현재 값과 변경 버튼, 터미널 미리보기,
건너뛰기·시작하기를 보여 준다. 선택한 행 안에 동일한 설정 액션을 쓰는 컨트롤을 펼친다.
앱 하단바와 에이전트 상태줄을 구분한다. 즉시 적용·새 작업부터 적용·재시작 필요를 구별한다.

| 구성 | 구현 매체 |
| --- | --- |
| 탐색 목록, 요약 행, 펼침, 선택 컨트롤 | 기존 native wgpu UI와 테마 토큰 |
| 캐릭터 얼굴 | 설치된 실제 테마 이미지와 SettingsMediaCache |
| 터미널·상태줄 미리보기 | 예시로 명시한 native 텍스트와 실제 선택값 |
| 시작·건너뛰기 | 고정 하단의 기존 아웃라인 버튼 |

저장 계약은 공통 설정 액션을 사용하며 첫 설정만의 별도 저장소는 만들지 않는다.
에이전트 권한 기본값은 기존 설치의 동작을 보존하고 명시적 CLI 설정을 우선한다.
상태줄 표시를 숨겨도 협업 상태 보고를 끊지 않는다.

## 구현·검증 기록

단일 빠른 설정에 네 요약 행과 인라인 펼침을 구현했다. 터미널 글꼴·프로필 가져오기는
추가 펼침 안에 두고, 저장·재시작 안내는 시작·건너뛰기와 같은 고정 하단에서 표시한다.
상태줄은 기존 설정 상속을 기본으로 하며 전체 조정 스위치를 켰을 때만 개별 표시값을 적용한다.
권한 선택은 실행 래퍼에 연결되며 기존 설치의 기본 동작과 명시적 CLI 설정 우선순위를 보존한다.

독립 검토 최종 PASS. 글꼴 기본 접힘, 데스크톱·640×720의 스크롤 여백,
박스형 에이전트 안내 제거를 화면으로 확인했다. 고정 하단 피드백과 탐색 클릭 영역의
클리핑 분리는 코드 검토로 확인했으며 저장 실패 화면과 실제 탐색 클릭은 실행하지 않았다.

자동 검사: `native_*` 67개, `agent_preferences` 5개, CLI 9개, Python 2개,
Codex shim 불변식 1개 통과. 가운데 정렬 검사는 의도적으로 깨뜨린 변형을 검출했다.
격리 API에서 상태줄·권한·기본 에이전트·잘못된 입력·복원·저장값 유지와 무관한 설정 구조 보존을 확인했다.
서명된 `dist/kasaterm.app` 빌드 성공. 실제 제공자 세션·Windows 실기기·저장 실패 UI는 미검증이며
사용 중인 앱은 재시작하지 않았다.

증거: `.impeccable/verification/setup/`의 전체 요약·모양·에이전트·터미널·좁은 화면 캡처.
항목별 판정은 `docs/settings-onboarding-redesign.md`에 기록한다.
전용 디자인 검토자·에셋 제작자 역할이 없어 새 독립 일반 에이전트로 대체했다.
새 프로덕션 비트맵 없이 기존 테마 이미지와 `SettingsMediaCache`를 재사용한다.
