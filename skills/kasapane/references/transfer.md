# 세션 이사

Claude·Codex를 다른 기기로 옮길 때만 읽는다.

- `kasaterm-cli machines`와 `where`로 기기·칸을 확인한다. 기기 이름·SSH 주소·포트를 추측하지 않는다.
- `kasaterm-cli machines move <현재 칸> <기기>`로 보낸다. 본인 칸이면 번호를 생략한다. 다른 기기에서 데려올 때는 이쪽 거울 칸을 대상으로 도착지를 `local`로 준다. 정확한 옵션은 `kasaterm-cli machines move --help`.
- 기본은 턴이 끝난 뒤 이동한다. 본인이 신청했다면 예약 응답 뒤 턴을 끝낸다. 자기 턴 안에서 도착을 기다리면 이사가 시작되지 않는다.
- 현재 이사는 대화를 옮긴다. 미커밋 파일·미푸시 커밋·`/tmp`·cwd 밖 자료·장기 프로세스는 자동 운반되지 않는다. 필요한 파일과 재개 지점을 먼저 정리하고, 도착 경로의 남의 변경을 덮지 않는다.
- 예약 접수는 완료가 아니다. 도착 기기에 같은 대화·모델과 실제 입력창이 준비됐는지 보드·화면으로 확인한다. 그 뒤에만 출발 맥북을 닫아도 된다고 안내한다.
- 자동으로 다음 일을 시작한다고 가정하지 않는다. 요청에 재개가 포함됐다면 도착을 확인한 최신 주소로 남은 일을 전달한다.
- 실패·시간 초과는 상태 미확인이다. 확인 전에 원본을 닫거나 강제 종료·`--force` 재시도를 하지 않는다. `--force`는 턴 중단·도착지 충돌 덮어쓰기를 허용하므로 기본 절차에 쓰지 않는다.

사람의 드래그는 학생 칸·탭을 다른 기기의 방이나 기기 머리에 놓는다. 코드 수정·덮개 이사 설정을 다룰 때는 카사텀 저장소의 `docs/session-transfer.md`·`docs/lid-away.md` 중 필요한 절을 읽는다.
